业务事实来自2026-11-10已有认证读取的归档：ERPNext预执行冻结记录、MES执行上下文，以及平台返回的步骤映射元数据。只公开必要白名单字段与实体编号，去掉租户/用户/知识库UUID、地址和凭据。投影自身哈希与上游完整载荷哈希分别标识，不能混称为同一原文；MES执行响应的work_order展开为投影根，batch/step保留各自层级。

**2026-11-11整理时Docker引擎未运行，本轮未实时复读ERP/MES或数据库账本，也未启动或改变任何环境。** 历史投影明确标为 `live_verified_this_batch=false`，不能代替当前授权或实时来源校验。未来用于真实接口评测前，要另行核对当前身份、父子选择、来源修订、资料状态和步骤映射；来源变化须重新采集并建立新版本，不能回填本候选。

## 题目结构与后续使用

每题包含 `input`、`expected`、`evidence`、`review`、`provenance`。必答点指向证据ID；文档证据定位原文条目，业务证据定位具体字段路径和值。`expected.reference_answer` 是人工待审草案，`http_status` 与 `behavior` 也是待核定标准，不是本轮请求结果。

会话037—040保留多步操作协议；029—035等题包含明确前置条件。平台问答请求不接受完整 `input` 对象，不能把本JSONL直接上传给旧runner。首版只整理与封存，没有新执行器、自动评分门槛、线上样本导入或质量任务，不改变既有评分派发。

所有题目属于 `regression_candidate`，`independent_holdout=false`。现有16题及同类问题已用于多轮开发，相关题标注旧case ID；其他题也可能与历史98/40题及工程场景相似，不能按改写后的新编号宣称未见题。题目带工单与资料家族 `leakage_groups`；当前共享HC-A17/OP-20资料，不划分独立留出集。将来扩充未参与调试的工单/资料后，需按关联分组整体划分，不能把同工单不同卡、批次或步骤拆到开发与留出两边。

人工复核应另存结论、审核者、时间、争议和原文依据，再产出新版本；本首版原件及全部历史题集/成绩继续保留。候选文件不提供绕过当前权限的正文访问，也不自动授予业务review权限或代替运行平台的来源登记与审核流程。
