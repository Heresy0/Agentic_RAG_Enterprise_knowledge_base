## 输入与验证边界

27 份非扫描资料使用实际格式解析器。6 份中文扫描件读取旧真实运行保存的、已经规范化的 OCR 页文字，先核验对应原 PDF 的 SHA-256，再重放两版后续解析和切分；其中 MFG-ZH11 的空 OCR 页在两版都被阻断。制造业 lite 的另外 2 份扫描件未纳入本轮重放，现有扫描夹具由回归测试覆盖。

这次对照证明本批资料的正文和结构没有因清洗重构改变，不是新 OCR 实验，也不是视觉模型或真实检索问答验收。扫描字符错认与困难扫描件问题仍然存在，OCR 分块继续标记待复核，不能据此宣称准确率提高。

本地原始快照、完整 OCR 页观察和辅助脚本保留在忽略目录 `tmp/`，没有作为新基线提交；其路径与指纹在 provenance 中列出。因此本报告提供本次本地对照的精简证据，重新执行扫描件对照仍需这些观察文件或重新生成并另行记录 OCR 输入。原有基线报告未覆盖写入。
