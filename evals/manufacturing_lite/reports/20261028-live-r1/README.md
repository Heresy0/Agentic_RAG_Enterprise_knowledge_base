## 运行与用量

模型为 `qwen3.7-flash`、`text-embedding-v4` 和 `qwen3-rerank`。本轮 20 个请求均由真实 Keycloak 令牌访问 `/api/qa`，再由同一所有者读取 `/api/qa/runs/{id}`。通过当前权限检查的模型账本 API 获取真实 event ID，与快照用量条数核对一致。

| 阶段 | 物理模型调用 | 供应商报告 Token |
| --- | ---: | ---: |
| 17 份资料入库 | 166 | 112018 |
| 20 题问答 | 64 | 193215 |
| 合计 | 230 | 305233 |

问答包含 20 次查询嵌入、20 次重排、20 次答案生成、3 次问题规划和 1 次 Agent 决策。账本调用均持久化，用量均已知、无调用错误；未配置模型单价，不报告金额，也不将费用视为零。明细汇总见 [ledger-summary.json](ledger-summary.json)。

评分及语义复核复用这 20 次真实 HTTP 结果，未再次调用模型。统一评估器中的 `mode=replay` 表示评分步骤读取已有观察，不能算另一轮真实验收。HTTP 快照未提供向量、关键词、融合和重排候选全过程，因此本轮不报告这些阶段的召回或排名成绩。

运行器最初将不含 event ID 的快照用量直接交给统一评分器，导致离线评分适配失败；随后通过已授权的账本 API 补齐真实 event ID 后完成评分。原请求及快照保留，未伪造 ID、用量或重做问答。相应转换和边界已有测试覆盖。
