# 300DPI＋空结果单次回退：离线OCR实验

**结论：收益不足且存在退化，本轮不替换应用默认配置。** 保留可选实验参数和全部结果；默认仍为220DPI、不开启回退。没有入库、重建索引或调用应用模型。

## 固定实验与实测

实际OCR前冻结两配置及检查项：A为220DPI、默认PSM3；B为300DPI、默认PSM3，仅空结果时用同一图像再运行一次PSM6。不旋转、去噪、二值化、去水印或猜测替换文字，不按答案挑配置。

3份独立原件共37页，来自浙江工程质量检查资料、陕西实训设备采购合同、内蒙古信息系统采购合同。选定9页27处检查、3段转写；旧6份扫描件选取覆盖全部55处原有扫描证据的12页。总计21个页面分别真实运行两配置。

候选共回退3页。两个容器和测试有并行负载，耗时只代表本次运行，不能当作独立性能基准。

旧证据总数相同掩盖了3处改善和3处退化。退化包括原先匹配的卡规分度值/范围与读数比较条款、检具精度能力系数；独立样本也有一处交付条件退化。因此不把净增加1项当作可默认启用的依据。

## 关键反例

- 陕西合同第2页：原件计算机行的单价7350.00、小计147000.00在A文字中仍有，B中均缺失。两配置均未可靠恢复整张表的行列与型号。单元格匹配不能替代表格关系验证。
- 工业内窥镜第6页：B回退后由空变成零碎字符，原文证据仍未匹配。非空不等于正文恢复，也不能据字数增加自动放行。
- 浙江样本第6、10页原始方向倒置/侧置。未旋转OCR输入，这些难例保留在评分中；本轮方案不解决方向问题。

3段参考片段的最小子串编辑距离为：浙江检查段2→0（35字符），陕西参数段54→54（64字符），内蒙古监督段0→1（96字符）。这是有限片段指标，不是整页CER，也不是问答准确率。

## 保留与验证

- 旧制造业基线及中文v3原文、题集、两轮报告共194个已提交文件字节不变；新3份原件与实验单独保存。
- 全量测试1,435项通过、55项跳过、0失败/错误；14项新增回归覆盖默认行为、空结果单次回退、非空差结果不改写、DPI限制、冻结输入及指标边界。
- 同一已有镜像、同一Tesseract5.3.0，chi_sim+eng，两个禁网只读容器。临时结果单独可写，业务数据和密钥不挂载。
- 原有`120/150`分块基线没有被本次页级实验改写；不把旧55处页文字的变化直接加到分块指标上。120题未运行模型问答。
- 标注与复核由同一助手完成，非专家认证；只有3份新材料和选定页面，不能声称广泛泛化或全37页通过。
