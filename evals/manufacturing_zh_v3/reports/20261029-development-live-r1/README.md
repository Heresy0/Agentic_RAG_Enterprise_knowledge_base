## 失败与评分差异

- **Q025：最终上下文漏证据。** 原文和存储子块有“不是用于合格性判别，仅供参考”，但本题最终上下文未包含，发生误拒答。另一题Q021实际上下文曾包含同一注释。尚未观测向量、关键词、融合和重排中间阶段，不能唯一归因到某一步。
- **Q034、Q083：证据已在，回答遗漏条件。** 分别遗漏按说明书预热、达到温度平衡；不能把“4小时”或“30min”单独答对当作完整通过。
- **N07–N10：缺少明确追问。** 三题识别出信息不足后直接拒答，一题直接列出多份设备规范；都没有按冻结要求让用户补充具体设备、问题或报告类型。自动评分有三题仅凭拒答判通过，语义复核保留为失败。
- **六处自动词面误差。** Q004、Q031、Q035、Q046、Q049、Q050分别涉及语序、否定同义表达、数量表述、范围括号、厂家同义词和端点表述。语义复核通过，但自动30/40没有改写，也没有修改参考答案或评分规则。

这是一轮首次中文开发集成绩，与旧英文／跨语言50题的来源和分母不同，不能直接计算提升幅度。后续可先处理澄清行为、必要条件覆盖，以及漏证据题的中间阶段观测和表格章节归属；复测应另建轮次，不覆盖本轮。
