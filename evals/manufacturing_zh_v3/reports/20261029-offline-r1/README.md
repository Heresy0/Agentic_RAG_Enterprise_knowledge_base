## 已确认的差异

44处未匹配按首次观察到差异的阶段划分：9处原生PDF逐页提取不再保留连续原文，5处逐页文字仍含锚点但切分/页归属后不匹配，30处扫描页OCR文字差异或缺失。这些是逐字证据检查结果，不等于44道错题，也不证明每处相关信息全部丢失。

1. **工业内窥镜扫描原件（MFG-ZH11）**：18页原件仅2页留下非空OCR文字，最终仅1块。原始扫描正文可人工阅读，并有印章、纸纹、拍照背景和扫描水印；物理第6、7页的题目证据未进入分块。整份资料阻断全量验收，原件和困难题保留。
2. **第75号令（MFG-ZH01）第6页**：实际提取拼接成“实行零生产单位应当……”等片段，零风险报告及周、月记录名称的完整表述未连续保留。不能因为页面有文字就认定条款完整。
3. **压合机规范（MFG-ZH08）第7页**：20%、40%等数值在布局提取中被移到后面，原句不再连续；第8页重复测量的完整句子仍存在于逐页提取文字中，但在分块中被拆开。两种问题分别记录。
4. **表面轮廓测量仪（MFG-ZH12）第6页**：OCR将`20±3`识别为`2043`一类错误，温度单位及变化率也有损失；扫描表格没有重建成可靠的行列结构。校准球等原页单元格证据未匹配。
5. **同轴度测试仪（MFG-ZH17）**：下标`l0`的`0`与正文错位，出现“不需0校准”等拼接；稳定时间的数字也未留在正确句子内。

其余未匹配逐条保留于`readiness.json`，包含原文锚点、物理页、是否仍在逐页提取结果中、其他页分块命中位置和首次差异阶段。没有通过放宽符号、缩短锚点、替换原件或回填OCR来掩盖问题。扫描表格、公式、单位和上下标未通过全文语义认证。
