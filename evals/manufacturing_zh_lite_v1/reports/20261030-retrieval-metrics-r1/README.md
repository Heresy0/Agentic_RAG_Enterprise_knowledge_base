## 测量口径

- 固定K为1、3、5、8；Hit、必要证据Recall、MRR和全证据完整率分别计算。每个K都先截取实际列表，再选择该范围内满足条件的已接受证据集合。
- Recall分母为每题标注的必要证据，按题取宏平均，不是全库穷尽相关性召回。缺观察不填0；资料不足/澄清题没有正例证据时不参与检索指标分母。
- 保留原指标及答案评分；新增实现放在独立模块，不改冻结的`metrics.py`。新报告记录该模块指纹，分组报告同样输出固定K指标。
- 本次98题实测直接复用正式`RetrievalService`、`ContextBuilder`及候选配置，是初始检索和上下文测试，不执行答案生成、追问改写或Agent后续补查。候选实际保留12条重排结果，@8是统一前8条观察，不等同实际列表的全部内容。
- 分层测试在本机进程使用现有隔离三库及正式JWT验签，只将容器内部连接地址映射到已发布的本机端口。嵌入为`text-embedding-v4`，重排为`qwen3-rerank`。
