## 原文与裁判复核

- **N09**：基线将不明确的具体问题直接回答成通用整改流程；候选改为追问环节、风险和已有措施。类型改善，但尚未直接追问问题现象，且风险等级可能需要用户进一步判断，追问质量仍有不足。
- **N10**：基线无追问并以资料不足拒答；候选询问报告类型，不再直接给出未确认的接收人。
- **Q083，真实漏条件**：两版都有相同原文：“校准用测量标准器与被校同轴度测试仪应在测量环境中稳定不少于 30min,待温度平衡后进行校准。”基线回答同时包含30min和温度平衡，候选只保留30min。必要条件已经进入上下文，属于生成遗漏；不以Ragas分数上升或类型正确掩盖这一问题。
- **Q084，评分口径边界**：用户只问校准点是否包含零点，候选回答“不包括零点”。现有r13已将点数和满量程列为可选信息并认可“不包括”的等价表达，因此r13通过。Ragas仍受原短参考的主体省略和额外信息影响，事实F1为0、忠实度为1；保留原分数，不把它直接认定为答案错误，也不修改参考抬分。
- **Q006，裁判波动**：两版用户可见答案逐字相同，忠实度却分别为1与0.5。复核裁判中间输出发现，拆句改变了“确保履职”的规范语气，且对“只需”等措辞判断不同。因此不能把本题分差归因于提示改动。原始判定全部保留。

上述原文复核由助手完成，属于非独立复核。单次小样本不能证明Q083遗漏必然由本次提示引起；它足以说明目前不能宣称整体质量已提升，因此保持现有运行镜像。
