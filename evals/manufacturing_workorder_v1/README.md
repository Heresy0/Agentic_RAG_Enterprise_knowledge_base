# 制造业首期工单问答回归集

本集版本为 `manufacturing-workorder-v1-r1`，包含 40 道合成场景题：开发 16 题，回归 24 题。当前仅完成 M0 的题集、来源与契约检查，尚未执行制造问答 HTTP 验收，也没有本集问答成绩。

| 分组 | 题数 |
| --- | ---: |
| 工单事实与来源 | 6 |
| 适用版本与变更 | 10 |
| 跨文档作业与复检 | 8 |
| 表格、条件和数值 | 6 |
| 澄清 | 4 |
| 拒答 | 6 |
| 合计 | 40 |

[profile.json](profile.json)绑定资料清单、工单夹具、规则、Pydantic schema、题集哈希及验收门槛。[development/single_turn.jsonl](development/single_turn.jsonl)和[regression/single_turn.jsonl](regression/single_turn.jsonl)分别保存两组问题、人工编制的参考答案、必答事实、禁止结论、文档摘录及业务字段证据。

开发集使用 WO-017、WO-020 和 WO-023；回归集使用 WO-018、WO-019、WO-021 和 WO-024。WO-022 留给权限测试。相关工单变体和近似问题不跨分区，基础文件可以共用。全部题目在编制时可见，因此不称独立企业盲测或独立准确率。

问题输入仅使用问题与可信业务上下文，参考答案、题号、必答标签和关键用例编号均不能进入模型或知识索引。`business_context_binding` 是评测服务端使用的来源绑定，不能作为普通用户选择任意历史源版本的入口。

首期正式问答门槛为：自动代理与逐题语义复核分别至少 36/40；开发至少 14/16、回归至少 22/24；12 项关键题、10 道澄清拒答题以及 6 道数值条件题全部通过。完整权限、故障、页面与闭环门槛见[首期方案](../../docs/MANUFACTURING_PHASE1_PLAN.md)。

只读校验：

```powershell
.venv/Scripts/python.exe scripts/manufacturing_phase1_workflow.py check
```

校验核对原件字节、原文摘录、工单字段、分组隔离、关键题绑定、契约 schema、历史冻结评分文件和新包定义，不访问数据库、HTTP 或模型。即使重算清单哈希，擅自改变标准答案也会被拒绝；有意调整须建立新版本。

本配置独立于原制造业 98 题及通用 120 题。不得把未来局部补跑、评分修订或新旧版本结果拼成一次完整运行，也不把数据完整性通过当作答案正确。
