# 制造业100题黄金回归候选

基于[中文语料包](../../sample_docs/manufacturing_zh_expansion_v1/README.md)及原40题补齐100道中文候选，每题包含问题、标准答案、必答点、禁止结论、来源证据与逐题审核记录。按用户委托，100题均由助手完成非独立复核，接受为离线回归候选；独立人工、工厂业务及运行平台批准均为0。本轮未执行题目、调用模型或产生准确率。

001至040继承原制造问答候选的历史场景与前置协议，仍需核对当前来源、权限和环境。041至094围绕定位支架、传感器壳体和信号线束，各18题；其中每系列16道离线资料题、2道多步会话协议题。095至100为6道本地中文公开原件阅读题。

因此，新增部分共54道离线资料题与6道隔离协议候选。离线资料题的`http_status=null`，不假装已经对应某个制造HTTP请求；协议题保存明确的前置条件、步骤与预期409，但本轮没有执行。全套`executable=false`，不能把JSONL直接交给旧runner运行或宣称模型100题全对。

三个产品系列含18组参数化意图，属于受控回归覆盖，不等于54种独立业务能力。所有题目`independent_holdout=false`；同资料家族、同工单及关联卡、批次、步骤保持同组，不能按改写编号拆分开发集和盲测集。旧40题及历史16题已经参与过开发，不重新包装成未见题。

## 逐题审核结论

助手逐题核对问题是否明确、标准答案是否被原文支持、必答点是否对应所问、条件与例外是否完整、实体和引用层级是否正确，并检查反例及未知值边界。审核结果只接受为离线候选，不授予知识库权限、不批准工艺规程或步骤映射、不导入平台质量样本。

`reviews.jsonl`明确记录`reviewer_type=assistant`、`independent=false`、`human_reviewer=null`及逐题理由。没有虚构人工姓名、专家资格或工厂签字。旧40题原文件中的待审字段不改；新版本统一使用独立审核文件关联100题，不能把本轮助手审核回填为旧版本人工批准。

审核发现原036问“开工或Completed能否证明首件检验和签署完成”，原标准却额外要求回答2.0版连续3件等细节。新版本仅将该项移到`optional_facts`，不计为必答；“不能据状态确认完成、不能反推一定未完成、需查实际检验与签署记录”继续必答。原40题和旧评分原样保留，不倒改成绩。其他继承题的问题、输入、标准答案及原始证据保持不变。

3份合成台账的日期和时间在原文中存在连写，6处新参考答案仅补展示空格，保留原日期、时间及时区；原件没有修改，未生成或声称来自API的ISO字段、时间精度或当前状态。

## 来源与业务边界

48个来源包括6份旧业务原件、4份平台契约、8份历史业务或映射投影、27份新合成资料与3份既有中文公开原件。旧业务投影来自历史认证读取的白名单归档，本轮`live_verified=false`；不能替代当前认证、来源三次复读或映射修订核验。

合成文档和台账只作为文档证据，不冒充ERPNext/OpenMES实时字段。新增会话协议中的DEMO编号均为离线别名；后续须在新的隔离测试数据中建立真实ID对应表，通过GET核对父子关系、来源、权限，另行完成需要的业务适用性与有效映射审核，再执行协议。资料中“拟分配2.0”仍是未登记草案，不因本轮题目审核成为已批准映射。

公开题改用本地已有的质量管理数字化指南PDF、第75号令归档PDF及2024年追溯实施意见Markdown原文，没有使用缺少原始HTML快照的4份导读作为金标原文。PDF按物理页取证，跨页条款联读；Markdown按固定非空行定位。公开文本只解释已冻结版次，不认证当前法律效力、工厂适用性或全文再发布许可。

标准答案均由助手依据这些原文与字段整理，未读取旧模型回答来生成金标。引用分别保存原字节或LF归一化指纹，历史投影保存其独立数据哈希；原文件哈希、白名单投影哈希和上游载荷哈希不混称。
