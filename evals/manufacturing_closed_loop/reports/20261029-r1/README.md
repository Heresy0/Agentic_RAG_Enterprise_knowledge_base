## 链路与异常

- 18份冻结中文原件原样上传到新租户；12份普通资料和5份OCR资料就绪并明确复核发布，1份困难扫描件失败。1034子块／向量、538父块与SQL核对一致。
- 发布前的真实问答拒答且无引用。临时合成TXT完成待发布不可引用、发布可引用、过期修订409、更新后重新待审、旧版本原件409、原件哈希一致、撤回不可引用和删除8项检查，之后已删除。
- 实测普通问题、设备条件澄清、补充条件续答和切换仪器；ERP/MES实时查询及写入请求明确拒答。本轮没有ERP/MES系统连接。
- 一条实际OCR正例Q067回答量块标准器及偏差比较方法；仅有公共参考查看权限的角色成功打开引用对应PDF物理第5页，原件SHA-256匹配，OCR质量警告保留。Q058、Q074等也有可用输出；这不代表全部OCR数值可靠。
- OCR温度被识别成`(2042) CHA`且被模型复述的失败保留，已建立反馈并置于`needs_evidence / draft`，未编造参考数值、未批准导出。
- 另外2条演示样本生成2个固定版本；2次同配置预算评测各含2题，经过带`response_binding`的明确复核、比较后关闭1个演示改进记录。同配置重复运行只证明流程可执行，不构成质量提升证明。
- 两次503发生于Q020和Q064；账本显示生成调用约60秒后`APITimeoutError`，用量未知，未重试。MFG-ZH11的16页空OCR为永久文档错误，第1次失败即停止自动重试，保留待复核原件。

## 文件

- `summary.json`、`answers.json`、`failures.json`：分组指标、原始回答和失败清单，保留120题。
- `workflow-verification.json`、`document-lifecycle.json`：流程演示、预算任务、比较关闭及未关闭OCR问题。
- `pdf-citation-verification.json`、`acl-checks.json`：原件定位和权限检查。
- `index-audit.json`、`runtime-versions.json`、`provenance.json`：索引、模型配置、处理代码指纹与交付版本。
- `baseline-preservation.json`、`database-preservation.json`、`original-vectors-verification.json`：旧文件、业务表和旧向量核验。

剩余工作是OCR关键数值与符号、普通资料的证据选择和必答项遗漏、剩余澄清误分类，以及外部模型超时的产品提示；本轮未继续围绕单题局部优化。视觉解析须配置后另做独立实测。
