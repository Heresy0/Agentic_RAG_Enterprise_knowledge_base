# 保存答案的Ragas旁路评估

统一入口为`python scripts/evaluate.py ragas`，对照用`python scripts/evaluate.py ragas-compare`。默认题集已迁至`evals/current/groups/main/single_turn.jsonl`，与历史100题字节一致；补全参考使用`evals/current/groups/main/ragas_references_v1.json`，当前仅同步r10评分指纹，参考文本未改。复现下列r9历史结果时显式使用归档题集、规则与参考。新120题需显式指定当前完整题集及对应120题报告、trace，不把100题参考覆盖套到其他分组。

`scripts/evaluate_saved_ragas.py`只读取已保存的题集、最终回答和实际上下文，用Ragas评估事实正确性及忠实度，再与原规则评分对照。不调用问答服务、重新检索、修改知识库或覆盖原成绩。Ragas及兼容依赖放在可选的 `requirements-evaluation.txt`，不加入API/Worker依赖。

## 固定口径

- 事实正确性使用Ragas `FactualCorrectness`，`mode=f1`、`atomicity=high`、`coverage=high`，直接对比最终答案与原题集 `reference_answer`。
- 忠实度使用Ragas `Faithfulness`，输入原问题、最终答案及实际选中上下文；只补上原引用编号与文档名，不回取更多原文。
- 最终拒答使用保存的 `answer`与用户可见的 `refusal_reason`，不把内部正确草稿当成已交付答案。
- 原标准答案、问题日期、r9评分、事实标注和原始记录保持不变。输入按题号、问题哈希、题集哈希及最终回答一致性校验，缺失上下文或范围违规时在调用裁判前停止。
- 事实正确性0.8、忠实度0.9是运行前固定的诊断筛查阈值，不是校准后的准确率门槛。任一指标错误或无有效结论时筛查结果为未定，不计为通过或零分。

## 如何解释差异

事实正确性比较的是答案与参考文本中的结论。原参考答案有省略主体的短句，也可能包含现有规则允许省略的可选信息；正确的额外解释还可能超出短参考覆盖范围。因此低F1不直接说明答案错误。应检查结论拆解与双向蕴含的裁判理由。

忠实度衡量检索上下文是否支持答案，不判断这些材料在现实中是否正确，也不等同于完整回答了问题。拒答、没有可提取事实及真实冲突题应单列分析。范围、逐结论引用绑定、拒答质量、耗时及Token继续使用已有指标，不用Ragas替代。

裁判与业务生成使用同一型号模型，存在相关偏差；本次没有独立人工标注所有100个答案。保留原规则分与Ragas连续分，评分不一致的题需结合参考答案、实际上下文和裁判中间判定复核。[事实正确性说明](https://docs.ragas.io/en/latest/concepts/metrics/available_metrics/factual_correctness/)、[忠实度说明](https://docs.ragas.io/en/latest/concepts/metrics/available_metrics/faithfulness/)。

## 输出及退出状态

原始产物写入已忽略的 `evals/reports/system/`，可能包含授权业务正文：

- `samples.jsonl`：固定的100题评分输入。
- `protocol.json`：依赖版本、模型、来源哈希、指标参数及阈值，不含密钥。
- `scores.jsonl`：逐题指标检查点，保留错误和无定义状态。
- `judge-attempts.jsonl`、`judge-calls.jsonl`：裁判尝试、HTTP响应、用量及可见结构化判定；无响应的尝试用量仍为未知。
- `report.json`：连续分汇总、诊断筛查、与原规则的差异题及裁判新增用量。

退出0表示100题处理完成且无指标错误，1表示完成但有指标错误，2表示只完成部分题。低分和评分不一致不当成程序错误。裁判调用Token单独统计，不与原问答生成Token混记，也不把未知用量当零；未配置价格不推算金额。

## 完整参考与必答、可选边界

[ragas_references_v1.json](../evals/archive/xinghai_v4/ragas_references_v1.json)为同一100题增加自包含参考，不修改历史题集或r9评分规则。标注仅依据冻结问题、原参考、事实与语义检查及r9覆盖规则编写，不依据被评模型答案补齐。每题保留原参考、问题/参考指纹、完整原事实标准指纹、有效必答事实、可选事实及禁止主张。

- `required_reference`：补全对象、角色、日期、数值绑定和事实状态后的参考，作为原生Ragas F1的输入；其中的消歧背景不新增r9要求复述的事实项，业务必答仍以保留的`required_facts`及语义检查为准。
- `necessary_background`：原问题中的必要背景，供审阅核对；实际F1参考已写明所需主体及条件。假设计算不写成真实发生事件，验收要求不写成实际执行记录。
- `optional_information`：32题的可选补充，未输出不应视为遗漏；不传入F1参考。列表不穷举所有可能正确的额外说明。已有事实仍保留，错误补充仍应由事实复核和忠实度检查识别。

这没有把原生F1变成支持“可选项豁免”的自定义指标。它只避免把可选参考细节当成必须复述的召回项；答案正确但带有参考之外的补充，仍可能被precision扣分。故继续保留连续分、原规则与逐题分析，不把筛查当准确率。
