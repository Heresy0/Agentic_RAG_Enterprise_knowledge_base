# 父块上下文真实模型对比：2026-10-22

本轮没有证明模型选段带来质量或成本收益。默认 12,000 字符预算下，两组均没有触发选段；完整父块保留了原文，生成答案仍会遗漏条件或误解语义。补充的 4 组预算压力测试触发了 2 次真实选段调用，但模型均要求保留完整父块，最后仍因预算不足拒答。

## 对照与评判口径

- 2026-10-22 21:13:56 至 21:39:49（北京时间），120 题 × 2 组，单次配对运行，逐题交替执行顺序，没有为提高分数重跑错误题。
- 测试集含 104 道可回答题、16 道应拒答题；执行前冻结原题、参考答案、评分规则和 31 道条件/例外重点题。
- 使用项目真实鉴权、当前 SQL/Milvus 证据、检索、重排、Agent、生成和校验服务。测试用户权限和知识库前后快照相同：72 份文档、600 个子块、158 个父块。
- 两组运行参数唯一差异是 `rag_context_selection_enabled=false/true`；均保留完整父块作为默认策略，预算均为 12,000 字符，每来源上限均为 4。
- 模型为 `qwen3.7-flash`、`text-embedding-v4`、`qwen3-rerank`，使用用户已明确授权的项目现有阿里云北京端点。
- 耗时为本地后端完整问答调用及用量记录，包含检索、Agent、选段、生成与校验；不含起始登录、客户端初始化和 HTTP 网络往返。
- 完整语义正确率来自 Codex 助手逐题复核 Qwen 的最终交付答案，要求结论和关键条件/例外正确。关键事实对但漏必要限制仍不通过；题目已经给定的前提可不重复。这不是人工盲评或未见测试集的泛化准确率。
- 旧关键词代理分数保持原规则；没有把它作为语义正确率。拒答也没有算作“条件完整的答案”。

## 费用口径和结论

按[阿里云官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)的北京实时公开价估算：Qwen3.7-Flash 在输入不超过 32K 的档位为输入/输出每百万 token ¥0.2/¥0.8，缓存输入 ¥0.04；Embedding-v4 和 Qwen3-rerank 为每百万输入 token ¥0.5。观测到的最大聊天输入为 9,374 token，落在该档位内。

费用包含已观测的嵌入、重排、规划、Agent、生成和修复；未扣除免费额度、合同折扣。基线 5 次、开启组 4 次规划调用因结构解析异常没有记录用量，其费用未知，没有按零元补齐。表内金额只是有记录部分的估算，无法得出完整账单的精确差额。主评估与压力测试合计已记录估算 ¥0.981946。

当前保留完整父块的策略可以继续使用；本轮不支持宣传模型选段已经改善质量、降低拒答或节省成本。下一步最有证据支持的改进，是答案生成后的条件/例外覆盖检查、跨版本和计时语义校验，以及降低引用/计算校验误拒答。同时应在结构解析前保存原始模型用量，再以预先冻结且确实可压缩的长父块样本验证选段收益。
