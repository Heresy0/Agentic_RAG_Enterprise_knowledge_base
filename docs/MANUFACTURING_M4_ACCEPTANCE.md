## 正式失败后的修正草案

在上述 r3 原始验收和提交 `c7f80c7` 之后，仅收紧制造生成提示中的结构约束：业务字段逐字复制；一般要求不混入工单主语；版本依据列出实际开工及登记通知字段；比较按单版本指导书逐条输出；来源编号不带方括号；明确否定、边界和书面例外。没有修改冻结题集、评分、业务授权或证据校验，也没有针对题号填入答案。

这份提示修正尚未调用真实模型，不能称已消除误拒答。8002 仍运行上述已实测的 r3 镜像；源码提示与该镜像存在明确差异。后续应在新的候选标签和目录进行验证，原 r3 的 28/40 及其绑定报告不改写。
