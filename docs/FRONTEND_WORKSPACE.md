# 知序前端工作空间

本轮前端位于 `codex/frontend-workspace` 分支，沿用已确认的浅色布局、靛蓝控件和 Noto Sans SC 中文字体。源码已接入原有同源API；8000现有部署未更新，数据库、资料及历史记录未操作。

## 页面与功能

| 页面 | 功能 |
| --- | --- |
| 作业指导 | 工单、ERP工序及作业卡选择；指导与执行记录页签；来源字段侧栏；主动查询作业要求；文档和业务引用、反馈及问答快照 |
| 知识问答 | 全部可访问知识库或单库查询、补充作业条件、历史对话、追问、引用原文和反馈 |
| 文档中心 | 当前库文档概况、名称搜索、发布状态筛选、上传、索引任务、OCR复核与发布；只读用户可查看已发布原件 |
| 问答反馈 | 个人与共享反馈、评价筛选、回答快照、撤回评价 |
| 质量中心 | 共享反馈审核、证据摘录、样本标注、修订历史、回归版本与下载 |
| 评测与改进 | 样本版本选择、零模型或有预算评测、任务结果与复核、改进记录及验证关闭 |

通用、ERP、MES继续通过服务配置中的工作区入口切换，保留各自的API前缀和OIDC会话范围。ERP/MES默认进入作业指导，通用工作区默认进入知识问答。MES批次、步骤和审核映射复用原有模块。

当前接口在主动问答后返回适用性和文档引用，没有独立的指导书首页GET接口。因此，选择工单只读取业务数据；点击“查询作业要求”才向现有制造问答接口发送问题。首次回答直接呈现在指导区，保留原引用、反馈和快照控件，下方继续追问，不重复展示同一份回答。没有从工单名称猜工序，没有新增模型路由或改写后端回答。

## 本地预览

在仓库根目录执行：

```powershell
.venv/Scripts/python.exe scripts/preview_frontend.py --port 8788
```

打开 <http://127.0.0.1:8788/erp/>，点击登录并使用“使用企业账号登录”进入本地演示身份。无需填写账号或令牌。也可打开通用 `/` 和 MES `/mes/`。

预览服务仅绑定127.0.0.1，直接提供当前 `backend/app/static/` 源码和内存夹具。页面顶部始终显示演示标识；OIDC形状的登录夹具只属于这个独立预览脚本，业务应用不会挂载它。该脚本不导入业务应用、不读取私有配置、不连接数据库和ERP/MES、不调用模型或启动Worker。重启即重置演示数据；未配置的写操作返回明确提示，上传、索引、评测等后台工作需在真实后端中执行。

预览只为HTML/CSS/模块URL附加文件修改时间以避免开发缓存，生产资源入口仍为原同源 `/ui/assets/`。当前源码仍由原Dockerfile复制，无需新框架、构建工具或第三方前端依赖。

## 主要文件

- `backend/app/static/index.html`：页面、导航、表单与对话框。
- `backend/app/static/styles.css`：字体、控件、布局、窄屏与减少动效设置。
- `backend/app/static/app.js`：保留原API、权限和状态处理，新增指导阅读区与文档筛选。
- `backend/app/static/auth.js`、`quality.js`、`openmes.js`：保持原实现；`verification.js`只补充空状态提示。
- `backend/app/api/frontend.py`：只增加字体与许可文件的资源白名单。
- `scripts/preview_frontend.py`：独立演示入口，不是业务服务或认证服务。

本地字体来自 [Google Fonts 的 Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，由完整可变TTF转换为WOFF2，约7.8 MB，未按演示文案裁字；首次加载后由浏览器缓存，`font-display: swap`避免阻塞文字显示。许可与版权保留在 `backend/app/static/FONT-OFL.txt`，页面不请求第三方字体服务。
