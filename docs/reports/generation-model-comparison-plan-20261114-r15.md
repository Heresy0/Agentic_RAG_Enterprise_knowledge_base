# Qwen3.7-Flash与Qwen3.8-Flash固定输入对照计划

用户要求先对照现有模型与Qwen3.8-Flash。本轮只运行生成组件，不修改业务源码、提示、Schema、检索、校验或本地模型配置，不更新已有部署。

- 沿用r13在观察新模型前已选定的12题：004、006、010、012、021、026、043、051、060、064、091、095。以r12结果为基准，成功与失败各6题；不是随机样本或独立留出集。
- 每模型每题各3次，共72次预定生成，按题配对并交替先后顺序。所有次数均计入，不取最好答案；超时失败保留，不重试补跑，不调用修复、规划、Agent、向量或重排模型。
- 复用r13公开冻结请求，先离线重建当前消息和Schema并检查请求相等。两边只替换model，均显式添加`enable_thinking=false`，保留既有`reasoning_effort=none`、temperature=0、120秒及max_retries=0。显式关闭思考是本组件实验的共同设置，不修改线上配置；记录实际返回模型名及可用的reasoning token计数，不能由缺少该计数断言服务端行为。
- 新私有批次`tmp/manufacturing-generation-model-comparison-20261114-r15/`，独立72调用、300万预算Token、7200秒，未知调用预留32000 Token。预算控制下一次请求发起，不宣称严格墙钟硬截止。关闭后剩余额度不可复用。
- 仅使用当前已授权百炼目的地、既有凭据及同范围公开/合成中文资料、问题和演示字段；标签与期望答案不发送。模型/参数不支持或认证拒绝时停止本批，不悄悄切端点、改参数或换模型。

入口`scripts/compare_manufacturing_generation_models.py`分离freeze/run/finish。离线检查确认12份当前请求与r13冻结请求相同，模型调用0；3项Mock测试验证配对消息保持、调用预算、超时不重试、接口不支持时停止及批次禁止复用，全部通过。离线Mock夹具最初缺必填字段导致freeze失败，修正后重新冻结，未发生外部调用。

输入来自历史Trace重建，缺少部分原始文档头，不是完整历史供应商请求复刻；本轮两个模型收到的消息/Schema相同。宿主机组件实验不访问问答/来源API、运行数据库或Docker，不代表实时权限、三次来源校验或最终API交付。

结果逐次通过当前Schema、草稿准备、输出校验和渲染，再按不变v4逐条复核答全、无依据补充、来源绑定和禁止结论，同时统计耗时、Token和运行错误。语义为助手非独立判断，不自动调用评审模型；不把36次观察当成百题准确率，也不把同一题重复视作独立总体样本。旧百题成绩和历史文件保持，不自动追加完整百题。

官方说明：[思考模式](https://help.aliyun.com/zh/model-studio/deep-thinking)、[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。两款模型官方均默认开启思考，单独传`reasoning_effort=none`是否等效此前未验证，因此本轮显式统一模式。
