# 生成收敛版 r8 新增失败的 Trace 根因

本轮只读对照 r5 与 r8 的已保存 Trace，并离线回放当前纯校验函数。**11道“上轮通过、本轮失败”不能统一归因于生成提示：7道有明确的新语义错误，1道供应商超时，1道冗余生成触发既有数值误拒，1道空字符串/null契约问题，另1道存在前后判定不一致。** 未发现这11题因新增切分、回取遗漏或上下文预算截断而丢失关键证据。

这是助手非独立诊断，不是新模型评测。没有修改提示、规则、业务、题集、金标、历史回答或成绩；真实模型、API、数据库与Docker操作均为0，进程网络连接及DNS被审计钩子禁用。

## 为什么有的被拒绝，有的被放过

这不是单一“校验太严”或“校验太松”的现象，而是不同检查对象造成的结果：

1. **字段格式的确定性检查会阻止交付。** 019的空串虽然常被模型用作“无缺口”，却不等于契约要求的null；010文件名的数字则被当作业务数字。两者均可离线定位到确定分支，和真实资料是否足够是两回事。
2. **coverage主要检查结构，不能证明答全。** 当前每题大多只有一个Q1，模型自己选择aspect及claim_indices。027把错误类型的条件标成answered、022把同一个批号写两遍，都满足结构；一些制造题aspect甚至仅为“E”。这只能证明有一条关联记录，不能证明记录涵盖了真实所问要点。源码本来就标明语义完整性仍需独立复核。
3. **引用存在、数字出现，不等于关系正确。** 007所引现行指导书的普通数值集合含number:2，但带单位的数量只有1件/3件，没有旧2件；普通问答路径未执行制造带单位数量约束，因此不能据数字检查通过认定比较绑定正确。022的值真实但字段意义错；026的日期规则真实但本题适用依据错。
4. **来源里出现的事实容易被扩展成更强结论。** 048的未签署→已证实未完成、081的当前草案→即使审核完仍不可选，都是额外解释改变了结论范围。两题都不是后端补全引入：首次草稿已如此，completion为空，未触发修复。
5. **有明确否定答案时也可能被模型当成不足。** 083已经“读到且复述了”正确边界，却没有把它归入claims；此时增加同一原文的检索数量并不能据此保证答案分类改变。

对应代码只作定位，不在本轮修改：[coverage检查](../../backend/app/knowledge/answer_coverage.py)、[字段与上下文分组](../../backend/app/manufacturing/answer_context.py)、[适用性编译](../../backend/app/manufacturing/generation_models.py)、[数值/引用校验](../../backend/app/knowledge/answer_validation.py)、[既有修复流程](../../backend/app/knowledge/answer_repair.py)。

## 086的新增错误形式

086两轮都失败，本轮首次草稿额外出现“作业卡（代表步骤）”。同一资料1明确分开ERP工序/卡与MES批次/步骤；所问第二步骤D41-2未登记的信息也在该完整父块中。模型选取了相邻ERP段落解释MES问题，还主动加了两个实体等同的括号说明。引用同一文档并不能证明跨段落的实体关系成立。该新错误属于生成中的对象选择与无据解释，不是新的整题退步，也没有后端编译或补全来源。

## 可以确认和不能确认的结论

可以确认：这批新增失败主要发生在**读到证据之后的语义选择、结论范围、回答分类和输出契约**。11个判定退步中，7个有新的语义错误；002是调用超时，010是多写冗余内容后触发既有误拒，019是契约缺陷并藏有语义过断言，044有前后复核不一致。不能用一个“继续强调答全/少补充”的提示结论概括全部问题。

不能确认：新提示具体哪句话造成某次退步，或恢复某条旧提示就能改善。r5→r8同时包含之前的检索回退与契约修正，完整模型请求也未逐字保存；必要证据仍在只能排除已观察到的直接丢证据解释，不能量化上下文其他变化对模型注意力的影响。002也没有足够证据进一步归责供应商或网络。

本轮保留全部旧成绩和原始判定，尤其不因044口径问题回写80/100、81/100或比较JSON。没有实施修复、增加提示、领域规则、题号分支、模型调用层或重试。现有r8总分仍不能证明生成目标整体改善，新增失败的数量也应带上本报告的044判定一致性限制解读。

离线结果：11个主要案例、1个补充案例，10份有草稿的新主要案例均复现已记录校验错误或成功结果；010删冗余条、019仅空串改null两个机制探针通过。117份选定输入哈希保持，网络/DNS禁用，模型/API/数据库/容器操作0。原始私有批次保持关闭；新诊断产物位于 `tmp/manufacturing-answer-focus-regression-diagnosis-20261113-r1-final/`，不包含新真实模型成绩。
