# 作业指导简洁视觉预览（2026-11-17）

用户要求按已认可的问答与文档风格制作指导预览。本轮在现有未部署候选上新增作用域CSS和装饰图标；业务JS、API及后端不改，8000、Docker、数据库、模型、索引与评测均未操作。

## 设计

- 主内容左上角采用侧栏同款书本图标，面包屑保留文字；页面h1仅视觉隐藏，仍可供辅助技术读取。
- 深色横幅改为紧凑型号标题、执行层级标签及工单/工序信息；双轨装饰和重复英文标签在此候选隐藏，历史快照标识保留。
- 工单选择区采用白底、淡紫左边线，取消悬浮重叠；原有选择与主动查询行为保持。
- 指导正文用白色文档式阅读区，减轻装饰图标、边框与阴影；来源卡片、未知字段说明、引用、反馈和快照仍按原流程展示。
- 选择区、正文、执行记录与右侧来源在手机上纵向呈现。先前用户认可的文档上传区不改。

## 验证

84项既有Node前端测试通过，180个唯一ID及原表单约束保留。浏览器用独立预览固定演示响应检查HC-A17工单的OP-20工序级展示、指导正文、执行页签及历史恢复，历史标题正确显示“历史快照 · 工序级”。没有调用真实模型。

桌面1440×1000、手机390×844视觉复核；320及1024px无页面横向溢出，warn/error为空。未验证真实移动软键盘，不作真实ERP/MES或生产数据验收。
