# 运行故障诊断与固定输入稳定性实验 r13

本轮完成了两件事：补齐既有模型调用事件中的脱敏故障信息；在不改提示、Schema、检索、校验、模型及超时的前提下，完成12题各3次固定输入生成，以及3组各3次独立重排探针。

结果确认了两种不同问题：真实读取超时，以及相同冻结输入下的解释遗漏/错误推断。026出现一错两对，060出现一次正确、一次超时、一次错误推断；043则三次稳定漏答。没有据结果继续调提示或加规则，也没有宣称质量改善。

## 能得出什么，暂不能得出什么

- 诊断改动已在真实失败中提供了比外层异常名更具体的信息，且没有改变失败行为。这是可观测性收益，不是调用故障已经修好。
- 固定输入仍会出现正确/错误的切换，也有稳定遗漏；下一步更值得做单一生成能力因素的受控对照，而不是恢复旧格式兼容、增加转换层或继续扩充提示。
- 9次重排中2次超时说明现配置仍有运行故障，样本不足以决定超时值是否应调整。未测其他超时配置，不能宣称把5秒改大就一定解决。
- 本实验不改模型，也不比较候选模型，因此没有模型升级收益结论；没有自动追加模型选择实验或百题复验。
