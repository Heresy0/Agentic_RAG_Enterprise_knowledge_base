- 四项统计取消大面积卡片底色，以数字、分隔线及短靛紫色选中线建立层次，原筛选操作保留。
- 上传区保持有上传权限时常驻展示，改为淡紫色横条及线性上传图标；选择文件、上传并索引、所选文件和上传状态均保留。上传区位于统计之后、搜索筛选之前。
- 文档列表增加按扩展名区分的PDF、DOC、TXT、MD文件图标；文件名略加字重，版本与时间弱化。图标与文字使用现有HTML/CSS/SVG实现，无外部资源依赖。
- 发布状态使用圆点加文字，处理状态使用浅色标签；原状态名称、OCR提示、两类状态含义和操作权限保持。
- 统一目录标题、数量标签、细边框、行间距、悬停及操作按钮。手机继续使用字段卡片，上传区自然换行；新增样式均以文档中心为作用域。
- 文件名、状态仍通过textContent构造；不将服务端内容作为HTML执行，不改上传、筛选、复核、原件、删除或索引接口。
