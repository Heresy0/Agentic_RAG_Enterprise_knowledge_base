# 文档、管理导航及状态体验优化候选（2026-11-17）

按用户要求继续实施设计评审剩余三项，承接[前三项优化](frontend-task-flow-20261117-r1.md)。两轮候选均位于 `codex/frontend-workspace` 的本地工作区，尚未部署8000；原部署入口和数据不变。

## 调整

- 文档列表优先：按用户后续意见，上传区恢复为有上传权限时常驻展示，移除展开按钮；四项统计压缩并支持点击筛选，增加处理状态筛选与清除筛选。处理状态和发布状态分列，删除收进每行“更多”，仍保留原删除确认。手机将同一份表格数据呈现为带字段标签的卡片，不复制文档状态或操作处理器。
- 管理入口归并：侧栏保留“质量中心”和个人“我的反馈”；评测入口移入质量中心子导航，审核与回归样本在同一页。管理入口根据当前库权限展示，评测页维持质量中心父级选中态；缺少管理员权限时显示明确提示，后端权限与请求不变。
- 审核列表缩短间距，摘要与审核操作分栏，长反馈说明显示两行摘要，完整内容仍在审核详情中。添加已选样本数量，详情分隔证据区与编辑区，保存按钮保持可见。
- 状态与恢复：文档加载、失败、重新加载就地显示；更新失败时明确指出当前内容为上次结果。上传状态在上传区域显示，失败保留文件选择。审核队列加载失败移除等待占位；评测信息更新失败显示旧结果提示及刷新方向。
- 问答显示真实经过的等待秒数（每15秒更新），不推测后端阶段、不追加请求。成功取得答案即停止等待提示，避免后续历史列表加载覆盖答案。失败保留原始问题供用户确认后手动发送，不自动重发，不将补充条件重复写回输入框；切换范围或退出后的迟到响应仍受原revision/权限检查保护。
- 未获得可访问知识库、业务对象尚未核验、当前范围加载中分别说明输入区禁用原因。
