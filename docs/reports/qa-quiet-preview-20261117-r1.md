# 知识问答克制版视觉预览（2026-11-17）

用户要求参考调研方向先做知识问答预览。本轮只改index.html中欢迎区及普通知识问答的作用域CSS，不修改app.js、API或后端，不操作8000、Docker、运行数据库或模型。

## 设计

- 去掉深色欢迎横幅、重复英文标识和大幅双轨装饰，保留小型SOPilot图形，使用“你想查找什么？”与留白形成焦点。
- 限宽820px阅读区；输入框使用白底、轻描边、柔和阴影与深灰紫主按钮；保留原示例占位文案，不添加问题示例卡片。
- 历史、新对话、检索范围和选填条件降低视觉权重，保留原交互与键盘顺序。
- 回答去除整块卡片外框；正文、引用侧线、反馈与快照形成阅读层次。错误反馈仍有明确边界。
- CSS限定普通问答模式；作业指导、文档、质量及评测不采用本轮新样式。文档上传展开行为保留。

参考的是Docmost的内容层级、Claude独立阅读空间和Gemini有目的的视觉反馈；没有复制第三方组件源码，也未安装新依赖。

## 验证与限制

- 84项既有Node前端测试通过。解析对比保留全部180个唯一ID及68个表单控件属性集合。
- 独立预览以本地模拟账号登录，检查空白首页、固定演示回答、引用弹窗、新对话及文档页面隔离。没有调用真实模型。
- 桌面1440×1000、手机390×844视觉检查；320、1024、2552px检查无页面横向溢出；浏览器warn/error为空。未验证真实移动设备软键盘。
- 本轮为视觉候选，未提交、推送或部署，8000仍保留r6。
