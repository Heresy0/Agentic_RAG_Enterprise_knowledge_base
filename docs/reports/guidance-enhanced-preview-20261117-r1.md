# 作业指导强化视觉预览（2026-11-17）

用户明确要求先做一版强化视觉预览，8000不动。本轮只修改本地候选前端及对应测试；8000继续使用[已部署r5](frontend-visual-deploy-20261117-r1.md)。未操作Docker、业务数据库、模型或部署配置。

## 设计

- 深靛色作业头部突出型号、工单/工序及执行层级，使用装饰性双轨SVG线条；不显示虚构完成度、置信度或放行状态。
- 浅色选择面板与头部衔接，桌面将工序、作业卡及查询操作整合为一行；手机收紧头部，工单选择与重新核验并排。
- 指导正文采用文档式标题、英文装饰字标和浅色阅读边线；原回答文本、引用、反馈及快照入口保持。
- 来源侧栏独立呈现来源字段与适用文件；手机时间字段使用整行，原始时间、未知值和业务含义不改。

新增头部读取现有上下文的 `product_model`、`work_order_number/work_order_id` 和规范的 `operation_code` 字段；执行层级来自现有execution/batch/step对象。历史快照明确标注，来源失效或退出时同步清空新增身份展示。正文和动态字段继续以textContent呈现。
