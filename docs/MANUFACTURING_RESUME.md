# 制造业项目简历描述

项目名称统一为“面向制造业的工艺知识与作业指导平台”。以下两版按岗位侧重点选择一版，项目时间和个人负责范围按实际填写；自建开源系统联调应写明为个人项目或技术实践。

## AI 应用与大模型开发方向

**面向制造业的工艺知识与作业指导平台｜个人项目**

技术栈：Python、FastAPI、LangChain、Qwen、PostgreSQL、Milvus、Redis、Keycloak、Docker Compose。

- 开发多租户制造知识问答平台，结合BM25与向量混合检索、重排、父块原文回取和有限修复，支持工艺文档与业务执行记录共同参与回答。
- 只读接入自建ERPNext工单、工序和作业卡及OpenMES工单、批次和步骤，实现具体对象的会话绑定、已审核指导书选版与步骤版本分配。
- 将字段展示和引用绑定放在后端，模型选择白名单字段或原文条目；校验回答覆盖、来源用途及版本，保留生成前后权限与来源核验，区分作业要求与实际执行状态。
- 建立反馈审核、样本冻结、版本化评分与调用预算验证；最新ERPNext 16题开发集自动评分16/16、助手非独立复核15/16，含8题模型参与，保留1题比较覆盖问题。

## 后端与制造业 IT 方向

**面向制造业的工艺知识与作业指导平台｜个人项目**

技术栈：Python、FastAPI、SQLAlchemy、Alembic、PostgreSQL、Redis、Keycloak、Docker Compose、Prometheus、Grafana。

- 实现OIDC认证、租户及部门/知识库授权、工厂业务范围校验，服务端计算检索权限，并在来源读取、回答交付和历史快照访问时复查。
- 为自建ERPNext/OpenMES实现只读适配，保留真实父子实体编号、字段值、源修订及时间精度；分别读取工单、工序/卡、批次/步骤开工，缺失值保持未知。
- 实现文档异步索引、反馈审核、不可变样本版本和预算Worker；来源或审核映射变化使旧样本失效，同工单对象按组隔离固定集与反馈集。
- 使用Docker Compose部署独立候选API、数据库副本、Redis及原件卷，复用既有只读上游和向量索引；完成33项零模型API冒烟及浏览器核心流程验证，并保留原ERP/MES环境。

## 简历一行版

基于FastAPI与混合检索构建制造业知识与作业指导平台，只读接入自建ERPNext/OpenMES，支持具体执行对象的会话、指导书版本审核、两类来源引用及反馈样本冻结；完成真实模型开发验证和零模型隔离部署。

## 面试展开重点

AI岗位优先解释三个决策：简单字段直接投影、模型只选择可验证来源、后端编译文字及引用并检查覆盖。以OP-30未知开工和Q010执行证据边界说明为什么单纯改提示词不足以保证业务正确。

后端岗位优先解释源系统与平台双侧权限、父子实体约束、来源修订变化对会话/冻结样本的影响，以及独立候选如何复用已有基础服务而保留旧环境。制造业IT岗位再补充“ERPNext工单/作业卡”和“OpenMES批次/步骤”两种对象模型的差异。
