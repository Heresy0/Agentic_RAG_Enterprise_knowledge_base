# 可靠性修复与扩容后验收（2026-10-13）

本轮完成可复现语料、请求治理、临时文件回收、授权查询和引用预览，并执行真实评估。分支为 `codex/expand-knowledge-corpus`，基于 `5ef2fc1`，本轮代码、语料快照和验收文档纳入独立的收尾提交。API 与 Worker 已重新构建和部署，三个健康接口均返回 200；已核对容器源码与工作区的关键文件哈希。

## 实施内容

- 原30份虚构业务语料及生成题集需要的原标注进入 `sample_docs/xinghai_base`，原文件内容和 SHA-256 保持一致。与已有20份扩容原文统一准备50份解析缓存，不再依赖开发者本机被忽略的旧输出目录。
- CI 准备统一语料、检查扩容生成一致性，安装 OCR 运行环境并严格验证解析与证据，执行前端认证、会话和引用预览测试。
- Git属性禁止对语料及统一题集自动转换换行，保证Windows与Linux检出后的原文字节、清单SHA-256和生成一致性检查保持一致。
- 嵌入请求默认30秒超时，可配置为大于0且不超过120秒。Redis 问答并发槽位自动续期，失效租约不能被恢复，租约丢失阻止成功返回；短租约也不会缩短同键内长租约的有效期。
- Worker 回收受管目录内超过保留期的孤儿暂存、备份与删除临时文件。默认24小时、每轮最多100个；保护被任务引用的文件、活动任务和正式文件缺失时可能用于恢复的备份，跳过链接和不能安全确认归属的路径。删除与回收按租户行锁串行，防止重命名继承旧 mtime 的文件被提前清理。
- 批量授权以固定4次查询汇总公共、部门和个人最高权限，保持有效租户、用户、部门及知识库检查。列表展示与全范围检索继续在请求时重新鉴权。
- 引用可点击预览当前分块原文。接口按租户、知识库、文档和分块限定范围，每次重新鉴权；失效引用返回404，撤权返回403，成功响应禁止缓存。页面使用纯文本渲染，切换范围或退出后清除预览并丢弃旧响应。
- 真实评估发现省略重复年份的历史对比问题被误当作单期查询。修复同年月份/日期与季度解析，保留两期证据；数字校验允许问题中明确同年的省略年份日期。跨年、多年份或无法确定年份的情况仍不猜测。

## 收尾边界与后续事项

本轮以已验证的功能和上述基线收尾，新增质量规则与模型调用优化留待后续独立迭代。现有固定阶段预算补全、事件编号格式、表头及根因句式识别属于领域启发式，存在样例耦合风险；尚无冻结的未见文档/题集和启发式消融结果，因此不宣称规则泛化已经通过验证。

后续优先增加小规模独立验证和消融实验，再决定哪些补全规则应保留、配置化或移除；保持权限、授权范围和证据安全校验。回答质量改进与评分器同义表达修正分别记录，不把评分修正计为模型回答能力提升。

项目展示定位为模拟企业场景的多租户知识库问答系统。当前语料为虚构测试资料，引用预览展示分块原文；真实企业接入、整份文档预览、长期负载、多轮与全部权限画像的部署验收均没有在本轮完成。
