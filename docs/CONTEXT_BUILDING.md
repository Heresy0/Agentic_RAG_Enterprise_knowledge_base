# 有预算约束的父块上下文

## 默认路径

检索、重排子块后，在授权及当前版本范围内回取父块。`ContextBuilder` 默认保留父块完整原文，不再按问题关键词删除章节。去重、正文优先、每来源限额及 12,000 字符的上下文上限继续生效；这里的字符预算只包含资料正文和资料头，不等于整个模型输入的 Token 上限。

普通子块沿用已有预算处理。父块不再执行首块字符截断，也不会因模型选段失败而退回旧关键词裁剪。

## 预算不足时的选段

某个父块的完整正文超过当前剩余字符预算时，才考虑一次模型选段：

1. 将完整父块按 `##` 标题划分成带 S 编号的章节，保留原文位置。
2. 固定保留前言、命中子块及命中章节，以及规则识别出的条件、适用范围、例外、否定、列表和表格章节。
3. 只有上述内容能放入剩余预算、有可靠命中锚点、存在可信用户身份和共享预算时，才调用模型。
4. 模型接收问题、父块原文及保护编号，只返回章节编号和 `use_full_parent`，不能返回改写后的证据。
5. 程序检查编号合法性、自动补回被模型遗漏的保护章节，按原顺序拼接完整章节，并再次检查命中原文和长度。

每个回答最多一次选段模型尝试，不按父块数量增加调用。规划、Agent、选段、修复和反馈再生成共享可选调用、Token 及时间预算。调用用量以 `context_selection` 阶段进入原模型账本；未知用量沿用保守预算预留。

复杂、多跳、比较问题，存在未解析的章节引用，章节结构不足或锚点无法核验时保留完整父块。模型请求完整原文、超时、无效编号、输出字段错误、内容无法缩短或保护后仍超预算时，同样保留完整父块。

完整父块仍放不下时，构建结果标记 `parent_context_budget_incomplete`。`AnswerService` 在生成前拒答，避免使用被截断的条件生成肯定结论；反馈补查产生这种上下文时也不进行再生成。纯上下文评估会把这个缺口记录为失败，即使较窄的证据标签仍然命中。

## 刷新、权限与引用

选段只在本次请求内复用，键包含问题、完整原文、文档/父块身份、索引批次、命中内容和适用性。刷新相同证据不重复调用模型；内容或身份变化不能复用旧选段。请求结束清除缓存，不在用户间共享。

模型调用前后重新检查身份权限；输入父块必须属于本次授权范围。权限和数据库错误继续向上传递，不能当成普通模型失败降级。

原父块正文保持不变，最终上下文记录原文区间、保护编号、补回编号、选择/回退原因。引用继续保留命中子块 ID 与父块 ID，全文引用预览仍返回数据库中当前授权父块的原文。

## 配置

| 环境变量 | 默认值 | 含义 |
|---|---:|---|
| `RAG_CONTEXT_SELECTION_ENABLED` | `true` | 预算不足时允许模型选段；设为 false 可复现完整父块基线 |
| `RAG_CONTEXT_SELECTION_OUTPUT_TOKENS` | `512` | 选段输出上限 |
| `RAG_CONTEXT_SELECTION_PROMPT_BYTES` | `16000` | 选段输入及结构化输出 schema 的保守字节预算 |
| `RAG_CONTEXT_SELECTION_TIMEOUT_SECONDS` | `6` | 单次调用超时，还受剩余共享时间限制 |

关闭模型选段不取消父块完整性保护；完整父块放不下时仍明确拒答。仅构建 `ContextBuilder()` 不会自行启用模型；真实问答和 live 上下文评估注入相同选段器。模型只在受控请求作用域内运行。

## 回归与边界

```powershell
python -m pytest tests/test_budgeted_parent_context.py tests/test_context_builder.py tests/test_answer_context_guidance.py -p no:locust -q
python scripts/evaluate.py check
```

回归包含：充足预算零额外调用、与问题无词面重合的条件/例外、模型漏选保护章节、完整列表/表格、前后预算边界、无效输出与超时、复杂依赖回退、共享预算、权限撤销、刷新复用、证据变化、实际生成与引用，以及不完整上下文不能伪通过评估。

规则保护覆盖已识别表达，不能证明任意自然语言条件都被完整识别；模型也可能自信地漏掉未识别的依赖。上线效果仍需用独立标注的完整性与答案正确性评测对比完整父块基线。本次不会自动增加真实模型调用的验收成绩。

本版按现有排名依次填充预算，不重新压缩已经入选的前部父块；仅允许一次模型尝试，可能增加预算紧张时的拒答率。每来源限额仍可能排除候选父块，父块之外的跨章节依赖仍需要检索与补查覆盖。以上均应在真实问题集上单独观察。
