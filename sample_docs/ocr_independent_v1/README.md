这3份官方公开原始PDF只用于OCR验证，不加入制造业正文库，不替换原有18份中文原文，也不计入现有120题。来源机构、主题、版式不同于原有吉林校准规范；没有将电子PDF转图片冒充扫描原件。

原件共37页，逐页检查均有图像且无可用原生文字层。实验只核查9个选定页面，不能声称37页全部识别正确。手写姓名、个人联系方式和银行信息未作为检查项。

来源URL、取得时间、大小、SHA-256及逐页文字层/图像检查见[manifest.json](manifest.json)。PDF保持下载字节；公开可读未被当作统一开放再分发许可。原件是OCR参考材料，不是对现行法规、合同效力或适用性的认定。
