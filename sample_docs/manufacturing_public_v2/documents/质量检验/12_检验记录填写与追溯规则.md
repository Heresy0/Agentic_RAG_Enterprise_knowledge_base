# 检验记录填写与追溯规则

文档编号：HC-QC-REC
版本：1.0
生效日期：2026-01-01
状态：现行
适用范围：衡川精密已授权人员

## 1 必填记录

首件检验记录必须填写工单号、批次号、指导书版本、量具编号、检验人、检验时间、逐项结果和质量签署。

## 2 借用量具

借用量具必须同时满足以下条件：

- 核对校准在有效期内，点检及零位确认正常。

- 登记借出方、借入方、量具编号和归还时间。

归还前清洁并复核状态；异常时隔离，不得只在交接记录中写正常后直接归还。

| 字段 | 允许值示例 |
| --- | --- |
| 记录标记 | 原始读数\|复核读数 |
| 空值说明 | 未检与零读数分开登记 |
