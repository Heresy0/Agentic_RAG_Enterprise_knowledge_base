# 工艺常见问题

文档编号：HC-FAQ-001
版本：1.0
生效日期：2026-01-01
状态：现行
适用范围：衡川精密已授权人员

## 1 作业与正式文件

问：FAQ和正式指导书写法不一致时怎么办？
答：先核对适用产品、工序和时间。同一场景内以已批准的正式文件为依据；仍有冲突时提交工艺负责人核实，不自行选择更宽松要求。

## 2 记录示例

下列示例仅展示记录字段，不是对任意工单的执行证明。

```json
{"work_order": "WO-EXAMPLE", "instruction_revision": "待核实", "note": "#不是章节|也不是表格"}
```

问：只有计划检验时间能否证明已完成？
答：不能，须查实际检验与签署记录。
