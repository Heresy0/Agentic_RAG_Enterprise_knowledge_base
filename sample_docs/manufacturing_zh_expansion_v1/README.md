# 制造业中文语料扩充候选

本资料包为后续100题黄金候选提供中文证据基础，包含55份不重复的逻辑文档：新增30份合成业务资料和4份公开资料导读，引用原有13份业务资料与8份中文公开资料。新增扫描件为0。全部保持待人工审核，本轮没有入库、问答、模型评分或运行平台审核批准。

## 资料规模

| 范围 | 新增文件 | 引用已有文件 | 合计 |
| --- | ---: | ---: | ---: |
| 原有制造业务场景 | 0 | 13 | 13 |
| 中文公开参考 | 4份简短导读 | 8 | 12 |
| 新产品合成业务资料 | 30 | 0 | 30 |
| 合计 | 34 | 21 | 55 |

格式合计为13份文字版PDF、4份DOCX、32份Markdown和6份TXT。其中新增文件为6份文字版PDF、25份Markdown和3份TXT；DOCX全部复用旧原件。没有为凑格式而复制同一正文，未新增扫描PDF，也未引入英文正文。

`sources.json`使用仓库根目录相对路径引用旧原件，不复制或重写原文件。新克隆需要保留完整仓库目录；本目录不能作为独立的55文件上传目录直接导入。

每系列10份：两道工序各有新旧版指导书，共4份；两份检验要求与样例辨析；一份变更通知；一份执行记录与离线夹具设计；一份工单例外草案；一份班次交接记录。新旧版使用不同条件、检查要求和缺项，产品间也有不同业务问题，不把替换编号视为独立知识覆盖。

所有产品、工单、批次、作业卡、步骤、参数和角色均为助手编写的合成演示设定，未经工艺或质量人员批准。尺寸范围等数值仅服务于离线检索和证据边界检查，不用于真实设备设定或产品验收。标题中的“现行演示版”指合成场景中的2.0版，不表示平台已经发布或批准。

## 中文公开资料

前8份引用[旧中文资料清单](../manufacturing_zh_v3/manifest.json)中的MFG-ZH01至08，覆盖质量安全责任、追溯、质量管理数字化及部分设备校准。选取的PDF均可直接提取中文文字，不沿用旧语料中的纯扫描件。这些是已冻结的历史版次，本轮没有认证其当前法规效力或工厂适用性。

新增4份文件是根据中文官方公开页面编写的简短导读，原文与助手补充的应用边界分别标注：

- [中小企业数字化转型政策解读](https://www.miit.gov.cn/zwgk/zcjd/art/2022/art_f2be257809da425cb6159c367940ccd5.html)：需求方、供给方、主管部门及循序推进路径。
- [智能制造典型场景参考指引2025年版](https://jxt.hubei.gov.cn/bmdt/rdjj/202505/t20250512_5646450.shtml)：工艺知识与生产进度等场景的区别。
- [智能制造标准体系建设指南2024版通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2025/art_03f60d66fa7b4b95abbea92d155da941.html)：版次、成文日期与发布日期的区别，未摘编附件全文。
- [质量强国建设纲要](https://www.miit.gov.cn/threestrategy/zcgh/zlgh/art/2023/art_f25b7ab14d4e492bba4ee7aef7412fa7.html)：质量基础设施与宏观目标的使用边界。

本轮通过网页读取工具核对官方页面；直接下载HTML的两次尝试分别因网络代理和HTTP错误失败，未取得原始HTML快照，不能声称已归档网页原件。导读不能替代原文进行逐条金标批准，后续涉及这些来源的黄金题需再核对原文并固定可复读证据。

公开可访问不等于拥有任意改编、全文再发布或商业使用授权。旧8份继续保留原来源及既有使用限制；新4份只提交短摘要、事实来源链接和明确标注的应用边界，不重新发布网站全文、图片或标识。政策目标、校准规范、企业作业要求和现场执行记录分别使用，不能互相替代。

## 与100题的关系

[coverage.json](coverage.json)整理60个新增证据主题，按18/12/12/12/6覆盖指导知识、ERPNext、OpenMES、来源边界和会话；加上保留的旧40题，对应后续30/20/20/20/10的100题规划。每个主题定位到新资料的具体条目，附原文与运行前置条件。

这60项是覆盖规划，不是60道已经写完标准答案或可直接执行的题目。旧40题仍全部待人工审核，不因本轮扩充自动升级为批准状态。当前没有新100题数据集、独立盲测集或准确率。

执行记录中的ERPNext工序与作业卡、OpenMES批次与步骤只是离线夹具设计，没有写入或从真实API读取。后续相关题需在新的隔离测试数据中核对实体父子关系、来源修订、权限、实际开工字段及审核映射；不能直接把本包文本当作上游业务证据。工单级实际开工未知时不取计划或子级时间补填，不能据此自动完成按工单实际开工的选版。

同一产品资料包、工单及关联子实体应整体分组。公共资料同一家族也保持关联，不把章节数视为独立来源数。所有新主题标记`independent_holdout=false`；未来划分留出集时需从未参与调试的整组场景中选择并另行冻结。

## 本地检查

```powershell
.venv/Scripts/python.exe -X utf8 scripts/check_manufacturing_zh_expansion.py --parse --probes
.venv/Scripts/python.exe scripts/check_manufacturing_gold.py
.venv/Scripts/python.exe scripts/evaluate.py check
```

新检查器核对数量、哈希、中文标记、格式、版本区间、草案状态、来源分组和覆盖引用；`--parse`调用未修改的现有解析器，检查55份资料及169条新证据在真实分块中的位置。检查过程禁止网络连接，不创建索引或数据库记录。五种损坏探针只修改内存副本。

生成源码为[业务内容](../../scripts/manufacturing_zh_expansion_data.py)和[构建脚本](../../scripts/build_manufacturing_zh_expansion.py)。新PDF使用ReportLab生成，构建需有ReportLab和可用中文字体；验证使用项目现有依赖。目标版本已存在时构建脚本拒绝覆盖。语义、参数、摘要及平台前置条件仍须人工审核，机械检查不代表业务金标批准。

验收结果见[本轮记录](../../docs/reports/manufacturing-zh-expansion-20261112-r1.md)。旧语料、题集、冻结评分、模型响应和报告原件继续保留，旧成绩不拼分。本轮不修改业务源码、权限、来源检查、ERPNext/OpenMES或隔离候选环境。
