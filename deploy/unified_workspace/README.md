# 8000统一工作台

统一入口提供三个工作区：`/`通用知识、`/erp/` ERP、`/mes/` MES。三个后端使用同一代码镜像，各自保留原数据库、原件卷和权限配置；Caddy只在本机8000发布入口，ERP/MES后端不发布8005/8006端口。

部署不合并或重写历史数据库。前端使用服务端root_path处理API、登录回调和退出地址；PKCE临时状态按工作区隔离。`UNIFIED_WORKSPACE_NAVIGATION=true`开启固定的工作区导航；独立部署默认不显示该导航。ERP/MES使用正常应用入口，不加载旧零模型部署包装器。

同一镜像从本机已有依赖镜像离线构建，requirements不一致时停止构建；不自动安装依赖。源代码先提交冻结，再导出Git归档构建。原镜像、容器配置、数据库备份及资料保留，用于回滚。

本机实际compose、模型凭据、OIDC客户端备份、构建日志和验收记录放在忽略的 `tmp/unified-workspace-8000-20261114-r1/`。不得直接输出或提交环境变量和私有配置。部署完成后的本机启动入口以该目录的compose为准，避免旧部署配置重新发布8005/8006。

现有数据库迁移版本、旧记录和原件须在切换前后核对；仅在确认无活动索引/评测任务后更新对应API和共享Worker。部署验收不重算旧黄金题成绩，也不自动重跑100题。
